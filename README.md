# 🎮 Gamergram  

Gamergram is a **next-generation social platform for gamers**, built to connect gaming enthusiasts worldwide.  
It combines community features, AI-powered interactions, and rich game data to create the ultimate hub for gamers.  

---

## ✨ Features  

- 🔐 **Custom User Authentication** – Secure login/signup with unique user management  
- 🤖 **Chat with Iconic Gaming Characters** – Powered by OpenAI API  
- 📖 **Sagas Mode** – AI-driven stories and conversations with legendary characters  
- 📌 **Game Tracking System** – Mark games as:
  - ✅ Completed  
  - 🎮 Playing  
  - 📚 Wishlist  
  - 🔖 Bookmarked  
- 🖼️ **Detailed Game Info** – Cover art, description, release date, and in-game screenshots  
- 📰 **Gaming News Feed** – Latest updates across all platforms  
- ❓ **Quiz Section** – Test and polish your gaming knowledge  
- 📊 **Quiz Dashboard** – Track quizzes won and win rate percentage  
- 👤 **Profile Section** – View all your bookmarked, wishlist, playing, and completed games  
- 🎭 **Random Avatar Assignment** – Unique avatar generated at signup  
- 🏠 **Attractive Landing Page** – Engaging first impression for new users  

---

## 🛠️ Tech Stack  

**Frontend:** React.js, Tailwind CSS, Framer Motion  
**Backend:** Node.js, Express.js, MongoDB  
**AI Integration:** OpenAI API  
**Authentication:** Custom JWT-based authentication  
**Deployment:** Render (Frontend), Render (Backend)
